# maldi-hic-processing

Author: John Abbey

Start date: 29.09.2022

Latest update: 29.09.2022

*IMPORTANT*: This script is designed to be fully automated, ie. it is not intended to be edited. All customisation can be performed in the parameter file.

This script receives a raw .imzML file and generates: 

   1). Processed data exported as a .imzML file, 
  
   2). a QC pdf for the associated file.

**Usage**: The script is run in command line and receives [4] arguments in the following format: 

    Rscript dir/full_processing.R arg[1] arg[2] arg[3] arg[4]

where:
  
  arg[1] = path to the raw .imzML file
  
  arg[2] = path to the peak annotation csv file
  
  arg[3] = path to the parameter file which can me modified to your requirements.
  
  arg[4] = the output path for the files generated by the script
